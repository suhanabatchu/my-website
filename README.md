# Recipes For U

A website for people looking to make easy recipes, and learn how to work around the kitchen 

## Files
- index.html: Home page
- recipes.html: Recipes page
- tips.html: Kitchen tips page
- request.html: Form where peopel can request recipes for me to post
- style.css: the one stylesheet used by every page
- script.js: the JavaScript functions
- .jpg: pictures used on the site

## How to open
Download or clone this repository, then open index.html in a web browser.
